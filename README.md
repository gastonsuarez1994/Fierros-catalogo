# Fierros · catálogo de ejercicios

Catálogo que usa la app **Fierros** para registrar entrenamientos. La app lo descarga al abrirse, así que los ejercicios nuevos aparecen sin reinstalar nada.

- `catalog.json`: ejercicios, grupo muscular y variantes. Cada variante puede tener una foto, indicada por planilla (`img/sN.webp`) y celda.
- `img/`: planillas de fotos. Cada planilla tiene 2 columnas × 15 filas; cada celda muestra el inicio y el final del movimiento.
- `hevy-map.json`: equivalencias entre los nombres de ejercicios de Hevy y los de Fierros, para importar el historial.

Este repositorio no tiene datos personales: los entrenamientos, pesos y fotos propias quedan guardados en la app.

## Fotos

Las fotos provienen de [free-exercise-db](https://github.com/yuhonas/free-exercise-db), publicada en dominio público (Unlicense), recortadas y agrupadas en planillas.
